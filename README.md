# 🖥️ Tin H5

> Nền tảng thi trực tuyến môn Tin học dành cho học sinh THPT, hỗ trợ ôn tập, kiểm tra kiến thức và đánh giá năng lực một cách nhanh chóng, chính xác.

## 🌐 Website

https://tin.h5.io.vn

## ✨ Tính năng nổi bật

* 📝 Thi trắc nghiệm trực tuyến
* ⚡ Chấm điểm tự động theo thời gian thực
* 📊 Thống kê số câu đúng, sai và điểm số
* 📱 Tương thích điện thoại, máy tính bảng và máy tính
* 🚀 Giao diện đơn giản, dễ sử dụng
* 🔍 Hỗ trợ luyện tập và ôn thi
